1. Game Pitch: «LPSBOX: Caja Negra Sísmica»

            

              Concepto Central: Cuando un terremoto sacude un edificio de varios pisos, el colapso de estanterías, plafones y energía eléctrica deja incomunicadas a las personas atrapadas en segundos. LPSBOX divide estratégicamente la supervivencia de los datos: dentro del edificio (Piso 2), el Nodo Sniffer motorizado por una Raspberry Pi 5 junto al acelerómetro MPU6050 ejecuta el algoritmo sísmico STA/LTA, activa la alarma local en pantalla completa y transmite de inmediato la fotografía de celulares t₀ hacia el exterior.
            

            

              Afuera, a salvo de cualquier derrumbe a 4.65 metros de altura en un poste de alumbrado público, el LPSBOX Gateway (caja minimalista sin pantalla con 3 LEDs de estado) almacena esa caja negra. El jugador encarna al Operario de Emergencia: llega al poste, verifica el LED Amarillo, acciona el malacate para bajar el Gateway del poste, extrae los registros por USB-C y determina cuántas personas había en cada uno de los 4 pisos antes del sismo.

🐍 Servicio Sniffer + Detector Sísmico en Raspberry Pi 5

            
Ejecutándose dentro del Sniffer (modelo3d.stl), la Raspberry Pi 5 procesa el MPU6050 por I2C, filtra MACs aleatorias cada 10 s, guarda la onda sísmica completa y transmite al Gateway del poste (ver python_rpi5_bridge/rpi5_lpsbox_bridge.py):

            

              

                rpi5_lpsbox_bridge.py (Sniffer RPi 5 + MPU6050)
                Python 3.11 · RPi 5
              

              
import json, time, math
import paho.mqtt.client as mqtt

def is_randomized_mac(mac: str) -> bool:
    # Bit Locally Administered (2, 6, A, E en segundo nibble)
    return mac[1].upper() in ('2', '6', 'A', 'E')

class StaLtaRecorder:
    def __init__(self, n_sta=20, n_lta=400, threshold=3.0):
        self.a_sta, self.a_lta = 1.0/n_sta, 1.0/n_lta
        self.sta = self.lta = 3.2e-5
        self.threshold = threshold
        self.event_waveform = []  # Guarda todo el evento sísmico

    def update(self, ax, ay, az, t_rel):
        dyn_g = abs(math.sqrt(ax*ax + ay*ay + az*az) - 1.0)
        e = dyn_g * dyn_g + 1e-6
        self.sta += self.a_sta * (e - self.sta)
        self.lta += self.a_lta * (e - self.lta)
        ratio = math.sqrt(self.sta / max(self.lta, 1e-7))
        self.event_waveform.append({"t": round(t_rel, 2), "g": dyn_g, "r": ratio})
        return dyn_g, ratio, ratio >= self.threshold

void OnMqttMessage(string topic, string json) {
  var data = JsonUtility.FromJson<LPSPayload>(json);

  // Mecánica 1: Spawns por piso (P1..P4) según conteo filtrado 10s
  buildingSpawner.SyncFloors(data.floor_counts);

  // Mecánica 2: Disparo sísmico MPU6050 + caída física de objetos
  if (data.sta_lta >= 3.0f) {
    propPhysics.TriggerSeismicShake(data.accel_g);
    seismogramUI.RenderFullEvent(data.event_waveform);
  }

  // Mecánica 3: Sincronía con los 3 LEDs del Gateway en el poste
  poleGateway.SetLeds(data.leds.blue, data.leds.blink, data.leds.yellow);
}
